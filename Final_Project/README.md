### [사용된 기술]
* **과일 낙하에 필요한 중력 연산**
* 등가속도 직선 운동 (Fruit.kt): 매 프레임 업데이트 루프마다 수직 속도 변수(dy)에 중력 상수(0.8f)를 누적 합산하는 오일러 적분(Euler Integration) 방식을 사용하여 하방으로 갈수록 빨라지는 자연스러운 자유낙하를 구현

* **다른 과일끼리 충돌 시 튕겨 나가는 구조**
* 두 과일이 충돌하는 순간, 충돌 방향(nx)에 비례하는 일정한 크기의 반발력 상수 값(0.5f)을 생성 후 한쪽 과일을 밀어내는 방식
* 위쪽 과일이 아래로 떨어지던 힘(top.dy)을 가진 채 부딪히면, 그 수직 에너지를 가로 방향의 구르는 힘(top.dx += slideDir * slideForce)으로 빗면 전환시켜 부드럽게 곡면을 타고 떨어짐

## <아쉬운 것들>
* 과일들의 이미지를 변경하는 스킨 모드를 제작해보고 싶었다
* 공식 앱으로 내려면 그래픽적으로 더 깔끔해야하고, 경쟁심리를 자극할 수 있도록 서버를 연결하여 실시간 랭킹을 표시할 수 있어야 할 것 같다

### 해결하지 못한 문제/버그
* 한 과일이 회전을 하게 될 경우 그 과일이 닿아있는 과일과 같이 톱니바퀴 회전하듯이 계속해서 회전하는 문제
* 같은 과일 끼리 부딪혀도 합쳐지지 않는 문제 - 발생률이 너무 낮아 왜 발생하는지, 어떤 조건인지 확인이 어려웠음

## 프로젝트 중 어려웠던 점
* 단순 이동 방식이 아니라 충돌이나 마찰력 등 여러 물리학적 요소들 제작하려고 하니 어려워 AI의 도움을 많이 받았다
* 별거 아니지만 직접 제작한 앱이 스마트폰이나 태블릿에서 보안 위험 앱으로 인식되어 설치할 때 마다 보안 관련 설정들을 전부 해제하는 것이 귀찮았음
